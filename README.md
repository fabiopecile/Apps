# Apps

## elfer-league

Browser-based Elfmeterschießen-Spiel mit Charakter-Creator (kaufbare Cosmetics), echten Shootout-Regeln (5 Elfmeter, Sudden Death, vorzeitiger Abbruch bei feststehendem Ergebnis), einem Liga-Auf-/Abstiegssystem und einem freischaltbaren Weekend Cup. Kein Build-Schritt nötig — einfach `elfer-league/index.html` über einen lokalen Webserver ausliefern (z. B. `python3 -m http.server` im Ordner) und im Browser öffnen.
